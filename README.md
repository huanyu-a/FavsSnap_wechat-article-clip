# FavsSnap

微信公众号文章剪藏工具 —— 将微信文章一键转为 Markdown + 本地图片。

## 功能特性

- **Markdown 转换**：自动将文章正文转为标准 Markdown 格式，支持标题、加粗、斜体、代码块、列表、引用等
- **图片本地化**：自动下载文章中的所有图片到本地 `images/` 目录，Markdown 中引用本地路径
- **批量剪藏**：支持一次粘贴多条链接，逐条处理，带进度条和百分比显示
- **贴图文章支持**：自动识别图文卡片类文章（贴图文章），提取文案和幻灯片图片
- **元信息保留**：自动提取标题、作者、发布时间，写入 Markdown 头部
- **可视化界面**：薄荷绿主题 GUI，圆角卡片布局，操作简单直观

## 安装

需要 Python 3.8+，安装依赖：

```bash
pip install -r requirements.txt
```

## 使用方法

### 启动

```bash
python main.py
```

### 剪藏文章

1. 在微信中打开目标文章，复制链接（支持 `mp.weixin.qq.com` 格式）
2. 将链接粘贴到「文章链接」输入框，每行一条
3. 选择输出目录（默认为脚本同目录下的 `output/`）
4. 点击「开始剪藏」

### 输出结构

```
output/
├── 文章标题A.md
├── 文章标题B.md
└── images/
    ├── img_A01_001_xxxxxxxx.jpg    ← 第1篇第1张
    ├── img_A01_002_xxxxxxxx.png    ← 第1篇第2张
    ├── img_A02_001_xxxxxxxx.jpg    ← 第2篇第1张
    └── ...
```

图片文件名格式：`img_A{文章序号}_{图片序号}_{哈希}.{扩展名}`，方便区分不同文章的图片。

### Markdown 输出格式

```markdown
# 文章标题

**作者**: 作者名
**发布时间**: 2026-05-21
**原文链接**: https://mp.weixin.qq.com/s/xxx
**抓取时间**: 2026-05-21 14:00:00

---

正文内容（Markdown 格式）

![图片](images/img_A01_001_xxxxxxxx.jpg)
```

## 支持的文章类型

| 类型 | 说明 |
|------|------|
| 普通文章 | 标准图文混排，完整转换正文和图片 |
| 贴图文章 | 图文卡片/幻灯片类文章，提取文案和全部幻灯片图片 |
